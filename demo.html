All features

Everything in the box

Every command the bot supports, grouped by purpose.

🗡️
Combat Tracker
Live embed posted to the player channel. Updates silently on every DM action — turn advances, HP changes, conditions, and notes.
/combat start /combat next /combat hp /combat condition /combat end
🧙
NPC Generator
Full Wildemount-flavoured NPCs with stats, personalities, ideals, bonds, flaws, and backstories. Saved to the campaign database.
/npc generate /npc list
📜
Quest Generator
Procedural quest hooks with Wildemount faction flavour. Colour-coded by difficulty. Post the active board to players on demand.
/quest generate /quest board
🗺️
Map Generator
BSP dungeons, zone-based outdoor terrain, template interiors, and Wildemount locations. Rendered as PNG and posted to the player channel.
/map generate /map share /map list
⚔️
Encounter Generator
Party-size and level-aware encounter generation. Outputs a full combatant roster ready to start immediately with /combat start.
/encounter generate
📖
Session Recaps
Log and archive session notes. Post recaps directly to the player channel as rich embeds. Browse history any time.
/session log /session history
⚙️
Campaign Management
Multiple campaigns per server. Switch between them. Full setup for DM role and player/DM channel designation.
/campaign new /campaign select /setup role /setup player_channel
🔒
DM Access Control
DM commands are guarded by role or channel — or both. Players only ever see what the DM deliberately shares.
Role gate Channel gate Ephemeral replies
💾
Two Database Modes
Run standalone with its own SQLite DB, or connect to the companion web app and share a database for a unified DM workflow.
Standalone Shared DB
🔊
Voice Channel Announcements
The bot joins a configured voice channel when combat starts and announces each turn via TTS — "Draketooth, round 2." Disconnects automatically when combat ends.
/setup voice_channel gTTS · ffmpeg
✅
Deploy Announcements
On every restart the bot posts a green embed to the player channel showing the commit SHA and what was deployed — so players know when the bot is back online after an update.
on_ready embed Railway env vars
What's next

Ideas for v2

Seven things worth building next, ranked roughly by impact.

🤖
AI NPC Dialogue (Claude API)
Wire in the Anthropic API so the DM can type /npc speak [id] "what do you want?" and get an in-character reply seeded from that NPC's faction, personality, and backstory. Cheap per call; could be cached with prompt caching.
AI Feature
🎲
Dice Roller with Roll History
Full dice expression parser: /roll 4d6kh3, /roll 1d20+5 adv. Results posted to player channel. The DM gets secret rolls. Track roll history per session for dispute resolution.
Quality of Life
🧝
Player Character Registration
Players register their own characters with /character create. Characters auto-join combat with correct stats, track their own HP, and appear in the tracker with a player icon rather than a monster icon.
Player-Facing
💰
Loot Generator
Challenge-rating-aware treasure tables with Wildemount-specific magic items (dunamancy crystals, Luxon shards). /loot generate [cr] posts a loot card; /loot claim [item] lets players mark items taken.
Quality of Life
🌦️
World Events & Weather System
Scheduled world events between sessions: faction movements, weather changes, rumours. The bot posts an "overnight report" to the player channel at the start of each session using a cron trigger.
Quality of Life
🌐
DM Web Dashboard
A lightweight Flask/FastAPI web UI that mirrors the Discord commands. The DM can manage campaigns, browse NPCs, and queue up maps from a browser. Shares the same SQLite DB as the bot.
Big Feature
🔍
Campaign Search
/search [query] full-text searches across all NPCs, quests, session notes, and lore entries. Returns ranked results with a preview snippet — a campaign wiki built from your actual play.
Player-Facing
